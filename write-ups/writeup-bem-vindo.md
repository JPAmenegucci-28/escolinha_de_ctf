# Bem vindo

* **Plataforma :** Escolinha CTF
* **Categoria :** WEB

**Objetivo :** Encontrar a flag inicial escondida na página principal da aplicação

Modelo de flag: FLAG{...}

* **ANÁLISE INICIAL :** 
Ao acessar a URL do desafio, é exibida uma interface simples somente com um texto (Bem-vindo) escrito ao centro do site, basicamente nenhuma informação em primeira instância ajuda a encontrar a flag.

* **RESOLUÇÃO :** 
Para resolver este desafio é necessário inspecionar a página do site para analisar o código HTML de sua construção, e ao observa-lo a flag estará localizada em um de seus tópicos resolvendo o desafio.
